# نمای کلی (Overview)

پلتفرم **MachineryManagerEnterprise** یک سامانه مدیریت دارایی‌های سازمانی (Enterprise Asset Management - EAM) است که اختصاصاً برای سازمان‌هایی طراحی شده که مالکیت، بهره‌برداری، تعمیر و نگهداری و مدیریت ماشین‌آلات سنگین و تجهیزات صنعتی را بر عهده دارند.

این پلتفرم با استفاده از جدیدترین فناوری‌های .NET توسعه یافته و از اصول طراحی دامنه-محور (DDD)، معماری تمیز (Clean Architecture) و ساختار یکپارچه ماژولار (Modular Monolith) پیروی می‌کند.

برخلاف نرم‌افزارهای سنتی تعمیر و نگهداری، MachineryManagerEnterprise کل چرخه حیات دارایی‌های عملیاتی را از مرحله تملک و خرید تا اسقاط و خروج از خدمت پوشش می‌دهد.

---

# چشم‌انداز (Vision)

ساخت یکی از جامع‌ترین پلتفرم‌های مدیریت چرخه حیات دارایی‌های سازمانی با توانایی مدیریت:

- تجهیزات و ماشین‌آلات سنگین
- ماشین‌آلات عمرانی و راه‌سازی
- تجهیزات معدنی
- ماشین‌های صنعتی
- دارایی‌های ناوگان حمل‌ونقل
- قطعات و کامپوننت‌های تعویض‌پذیر
- منابع و اپراتورهای عملیاتی

همراه با ارائه شفافیت کامل در ابعاد عملیاتی، مالی و تحلیلی.

---

# اصول بنیادین (Core Principles)

این پروژه بر پایه اصول معماری زیر بنا شده است:

- طراحی دامنه-محور (Domain-Driven Design - DDD)
- معماری تمیز (Clean Architecture)
- ساختار یکپارچه ماژولار (Modular Monolith)
- توسعه کد-محور (Code First)
- مدل دامنه رویداد-محور (Event-Oriented Domain Model)
- طراحی با محوریت چرخه حیات (Lifecycle First Design)
- زبان فراگیر و یکپارچه (Ubiquitous Language)
- اصول شی‌گرایی SOLID
- آمادگی کامل برای CQRS
- آمادگی برای تبدیل آتی به معماری میکروسرویس

---

# اهداف پلتفرم (Platform Goals)

این سامانه برای پشتیبانی از تمامی ابعاد چرخه حیات دارایی‌های سازمانی طراحی شده است:

- ثبت و شناسنامه‌دار کردن دارایی‌ها (Asset Registration)
- طبقه‌بندی و دسته‌بندی تجهیزات
- ساختار درختی سازمانی
- پروژه‌ها و کارگاه‌های عملیاتی (Job Sites)
- سیستم قرائت کارکرد و کنتورها (Meter Readings)
- مدیریت موتورها و محرک‌ها
- مدیریت قطعات تعویض‌پذیر (Replaceable Components)
- تعمیرات و بازسازی‌ها
- نگهداری و تعمیرات پیشگیرانه (PM)
- مدیریت مصرف سوخت
- مدیریت روانکارها و سیالات
- مدیریت هزینه‌های نگهداری و تعمیرات
- مدیریت مالی و استهلاک دارایی‌ها
- الحاقیات و ابزارهای جانبی (Attachments)
- پایگاه دانش و اسناد فنی
- گالری تصاویر وضعیت دستگاه‌ها
- سیستم اعلان‌ها و هشدارها
- گزارش‌گیری و داشبوردهای تحلیلی
- پیش‌بینی کارکرد و هزینه‌ها
- پشتیبانی از تصمیم‌گیری هوشمند مبتنی بر AI

# فلسفه معماری (Architectural Philosophy)

سامانه مقادیر جاری را به عنوان منبع حقیقت تلقی **نمی‌کند**.

در عوض، منبع حقیقت (Source of Truth) متشکل از موارد زیر است:

- اندازه‌گیری‌ها و سنجش‌ها (Measurements)
- تراکنش‌ها و رویدادها (Transactions)
- رویدادهای چرخه حیات (Lifecycle Events)

تمامی مقادیر محاسباتی (مانند ساعات کارکرد کل، بهای تمام‌شده، هزینه‌های نگهداری، ارزش دفتری و پیش‌بینی‌ها) از تاریخچه رویدادهای عملیاتی مشتق و محاسبه می‌شوند.

---

# دارایی‌های قابل رهگیری (Trackable Assets)

پلتفرم دارایی‌های عملیاتی را به عنوان اشیاء درجه اول دامنه (First-Class Domain Objects) شناسایی می‌کند:

- ماشین‌آلات (Machines)
- موتورها (Engines)
- الحاقیات و ابزارها (Attachments)
- قطعات و مجموعه‌های تعویض‌پذیر
- سایر دارایی‌های قابل رهگیری آینده

هر دارایی دارای چرخه حیات، تاریخچه و سوابق عملیاتی مجزا است.

---

# قطعات تعویض‌پذیر (Replaceable Components)

برخی قطعات قابلیت نصب، دمونتاژ، تعمیر، انتقال و جابجایی بین دستگاه‌های مختلف را دارند:

- موتور (Engine)
- گیربکس و سیستم انتقال قدرت (Transmission)
- پمپ هیدرولیک (Hydraulic Pump)
- فاینال درایو (Final Drive)
- باطری (Battery)
- تایرها و شنی‌ها (Tires & Tracks)

معماری سامانه تاریخچه کامل نصب و جابجایی قطعات را ثبت و نگهداری می‌کند.

---

# سیستم کنتورها و کارکردسنجی (Meter System)

پلتفرم از انواع مختلف کنتورها پشتیبانی می‌کند:

- ساعت‌شمار کارکرد (Hour Meter)
- کیلومترشمار (Odometer)
- مسافت‌سنج (Distance Meter)

قابلیت‌ها:
- تعویض کنتور
- قرائت اولیه و قرائت قبلی
- ساعات کارکرد مفید و غیرمفید
- تاریخچه تغییرات کنتورها

تعویض یک کنتور هرگز ساعت کارکرد واقعی کل عمر دارایی را صفر نمی‌کند.

# پشته فناوری (Technology Stack)

بک‌اند و رابط کاربری وب:
- .NET 10
- ASP.NET Core
- Blazor (Server / WebAssembly)
- MudBlazor

کلاینت دسکتاپ و موبایل:
- .NET MAUI (مطابق با ADR-0013 و TE-0010)

داده‌ها و کشینگ:
- Entity Framework Core (SQL Server)
- SQLite / LiteDB (پایگاه‌های داده محیط کار محلی)
- FusionCache (ترکیب IMemoryCache و Redis)

پیام‌رسانی و پردازش پس‌زمینه:
- MassTransit / RabbitMQ
- Quartz.NET

هوش مصنوعی و جستجو:
- Semantic Kernel (ارتباط با Azure OpenAI، OpenAI و Ollama)
- Qdrant (پایگاه داده برداری)
- جستجوی متنی SQL Server Full-Text (گزینه پیش‌فرض) و OpenSearch (در صورت نیاز به ارتقا)

احراز هویت و امنیت:
- ASP.NET Core Identity / OpenIddict
- HashiCorp Vault

مشاهده‌پذیری و پایش:
- Serilog، OpenTelemetry، Prometheus و Grafana

معماری:
- طراحی دامنه-محور (DDD)، معماری تمیز و یکپارچه ماژولار
