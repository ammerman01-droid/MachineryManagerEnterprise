# ۱. هدف (Purpose)

این سند مدیریت چرخه عمر APIها را در MachineryManagerEnterprise تعریف می‌کند.

---

# ۲. مراحل چرخه عمر API (API Lifecycle Stages)

۱. **پیش‌نویس (Draft)**: در حال توسعه، بدون اطلاع قبلی دستخوش تغییرات شکننده می‌شود.
۲. **فعال (Active)**: آماده برای محیط عملیاتی (Production Ready)، حاکمیت تحت نسخه‌بندی معنایی (Semantic Versioning).
۳. **منسوخ‌شده (Deprecated)**: علامت‌گذاری‌شده برای حذف در آینده؛ کلاینت‌ها باید مهاجرت کنند.
۴. **بازنشسته‌شده (Retired)**: از سرویس‌دهی خارج شده است.

---

# ۳. خط‌مشی منسوخ‌سازی (Deprecation Policy)

- اندپوینت‌های منسوخ‌شده باید هدرهای HTTP با نام‌های `Sunset` و `Deprecation` را بازگردانند.
- حداقل دوره منسوخ‌سازی: ۶ ماه پیش از بازنشستگی کامل.
