# هدف (Purpose)

این ارزیابی فناوری، پشته (Stack) فناوری‌های تست نرم‌افزار را برای پلتفرم MachineryManagerEnterprise تعیین می‌کند.

فناوری‌های انتخاب‌شده باید یک استراتژی آزمون جامع را پوشش دهند که شامل موارد زیر است:

- آزمون واحد (Unit Testing)
- آزمون یکپارچگی (Integration Testing)
- آزمون قراردادها (Contract Testing)
- آزمون زیرساخت (Infrastructure Testing)
- آزمون سرتاسری (End-to-End Testing)
- اتوماسیون رابط کاربری (UI Automation)
- آزمون رگرسیون (Regression Testing)
- اعتبارسنجی در یکپارچه‌سازی پیوسته (CI Validation)
- راستی‌آزمایی کارایی و پرفورمنس

پلتفرم تست باید کیفیت نرم‌افزاری در سطح سازمانی را تضمین کرده و هم‌زمان کاملاً با معماری تمیز مصوب منطبق باشد.

---

# دامنه ارزیابی (Evaluation Scope)

این ارزیابی فناوری موارد زیر را ارزیابی می‌کند:

- xUnit v3
- FluentAssertions
- NSubstitute
- Testcontainers
- Playwright

این سند موارد زیر را تعریف **نمی‌کند**:

- استراتژی کلی تست؛

- ساختار سازمانی آزمون‌ها؛
- خط لوله CI؛
- قواعد درصد پوشش کد (Code Coverage).

این تصمیمات معماری به‌صورت جداگانه در ADR مربوطه مستند خواهند شد.

# معماری فعلی آزمون (Current Testing Architecture)

معماری مصوب نیازمند آزمون در سطوح چندگانه است:

```text
                End-to-End Tests (آزمون‌های سرتاسری)

                       ▲

                       ▲
```

هر لایه معماری باید به‌صورت مستقل قابل آزمون باشد.

# ۸. ارزیابی xUnit v3 (چارچوب پایه آزمون)

## نمای کلی و ارزیابی

چارچوب xUnit استاندارد صنعت در اکوسیستم دات‌نت است. نسخه ۳ (xUnit v3) بهبودهای چشمگیری در اجرای غیرهمگام (Async)، اجرای کاملاً موازی (Parallelism)، بهینه‌سازی حافظه و کشف تست‌ها ارائه می‌دهد.

```text
                پروژه آزمون (Test Project)
                            │
                            ▼
                     xUnit v3 Runner
                            │
       ┌────────────────────┼────────────────────┐
       ▼                    ▼                    ▼
  Unit Tests        Integration Tests    Architecture Tests
```

- **مزایا:** پشتیبانی بومی از دات‌نت، عملکرد فوق‌العاده سریع، جداسازی کامل نمونه‌های تست، پشتیبانی عمیق از تست‌های مبتنی بر داده (`[Theory]`, `[InlineData]`) و یکپارچگی عالی با IDEها و خطوط لوله CI/CD.
- **ارزیابی:** **عالی (تأیید شد)**.

---

# ۹. ارزیابی FluentAssertions (کتابخانه گزاره‌ها)

کتابخانه FluentAssertions خوانایی تست‌ها را با استفاده از متدهای زنجیره‌ای شبیه به زبان طبیعی (مانند `result.Should().BeEquivalentTo(...)`) به‌شدت افزایش می‌دهد و خطاهای شکست تست را با پیام‌های بسیار واضح و کاربردی گزارش می‌کند.

- **ارزیابی:** **عالی (تأیید شد)**.

---

# ۱۰. ارزیابی NSubstitute (چارچوب Mocking)

کتابخانه NSubstitute به دلیل سینتکس تمیز، مختصر، پشتیبانی کامل از بازنویسی‌های غیرهمگام (Async) و عدم پیچیدگی اضافی نسبت به کتابخانه‌های قدیمی مانند Moq، به‌عنوان چارچوب شبیه‌سازی انتخاب شد.

- **ارزیابی:** **عالی (تأیید شد)**.

---

# ۱۱. ارزیابی Testcontainers (زیرساخت آزمون یکپارچگی)

## نمای کلی و نقش در معماری

کتابخانه Testcontainers امکان راه‌اندازی کانتینرهای واقعی و یکبار مصرف داکر (مانند SQL Server، RabbitMQ، Redis و Qdrant) را در حین اجرای تست‌های Integration فراهم می‌آورد و پس از پایان تست‌ها آن‌ها را به‌صورت خودکار معدوم می‌کند.

```text
               Integration Test
                      │
                      ▼
            Testcontainers Library
                      │
       ┌──────────────┼──────────────┐
       ▼              ▼              ▼
  SQL Server      RabbitMQ        Redis
   Container      Container     Container
       │              │              │
       └──────────────┴──────────────┘
            Disposable Infrastructure
```

- **مزایا:** حذف دیتابیس‌های تستی اشتراکی کثیف، تضمین قطعیت نتایج، شبیه‌سازی دقیق محیط عملیاتی و اجرای آسان در خط لوله CI/CD بدون نیاز به تنظیمات دستی سرور.
- **ارزیابی:** **عالی (تأیید شد)**.

---

# ۱۲. ارزیابی Playwright (اتوماسیون وب و E2E)

پلی‌رایت (Playwright) محصول شرکت مایکروسافت، مدرن‌ترین و پایدارترین چارچوب اتوماسیون مرورگر (Chromium, Firefox, WebKit) برای تست پورتال‌های وب، داشبوردهای مدیریتی و جریان‌های کامل کاربری است.

- **مزایا:** انتظار خودکار (Auto-waiting) هوشمند، حذف خطاهای ناپایدار (Flaky Tests)، ضبط ویدیو و تصویر از مراحل خطا و اجرای موازی بسیار سریع.
- **ارزیابی:** **عالی (تأیید شد)**.

|---|---|---|
| **اجراکننده آزمون‌ها (Test Runner)** | **xUnit v3** | فریم‌ورک پایه اجرای تست‌های واحد و یکپارچگی |
