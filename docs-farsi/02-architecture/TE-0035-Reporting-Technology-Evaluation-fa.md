# ۱. هدف (Purpose)

این سند به ارزیابی فناوری‌های کاندید برای گزارش‌گیری در سامانه MachineryManagerEnterprise می‌پردازد.

هدف اصلی، دستیابی به یک انتخاب یکپارچه از فناوری‌ها است که تمام الزامات عملکردی و معماری را برآورده ساخته و هم‌زمان اصول معماری پاک (Clean Architecture) را حفظ کند.

فناوری‌های انتخاب‌شده باید از موارد زیر پشتیبانی نمایند:

- تولید فایل‌های PDF سازمانی
- خروجی به فایل‌های Excel
- گزارش‌های قابل چاپ
- اسناد تجاری و کسب‌وکار
- گزارش‌های مالی
- گزارش‌های عملیاتی
- قابلیت نگهداری بلندمدت
- اجرای چندپلتفرمی

---

# ۲. محدوده ارزیابی (Evaluation Scope)

این ارزیابی فناوری موارد زیر را مورد سنجش قرار می‌دهد:

- RDLC
- ClosedXML

این سند موارد زیر را تعیین **نمی‌کند**:

- معماری داشبورد (Dashboard Architecture)
- استراتژی هوش کسب‌وکار (BI Strategy)

این تصمیمات معماری به‌طور جداگانه در سند ADR مربوطه ثبت شده‌اند.

# ۸. ارزیابی QuestPDF

## مرور کلی (Overview)

کتابخانه QuestPDF یک کتابخانه مدرن و متن‌باز تولید PDF برای .NET است.

این کتابخانه اسناد PDF را با استفاده از API روانی با زبان C# و به‌صورت کاملاً برنامه‌نویسی‌شده (Code-First) به جای طراح‌های بصری یا چیدمان‌های XML تولید می‌کند.

در MachineryManagerEnterprise، کتابخانه QuestPDF به‌عنوان فناوری اصلی تولید PDF سازمانی ارزیابی می‌شود.

---

# نقش معماری (Architectural Role)

```text
داده‌های کسب‌وکار -> Report Builder -> QuestPDF -> سند PDF
```

کتابخانه QuestPDF صرفاً مسئول رندر کردن اسناد PDF است. منطق کسب‌وکار کاملاً بیرون از موتور گزارش‌گیری باقی می‌ماند.

---

# نقاط قوت معماری (Architectural Strengths)

مزایا عبارتند از:

- پیاده‌سازی نیتیو در .NET
- API روان و قدرتمند
- اجرای چندپلتفرمی
- کیفیت عالی رندرینگ
- موتور چیدمان قوی
- توسعه فعال
- عدم وابستگی به طراح بصری (Designer)
- قابلیت نگهداری فوق‌العاده

# ۹. ارزیابی ClosedXML

## مرور کلی (Overview)

کتابخانه ClosedXML یک کتابخانه متن‌باز .NET برای ایجاد و مدیریت فایل‌های اکسل (Excel Workbooks) است.

برخلاف کتابخانه‌های اتوماسیون آفیس، ClosedXML فایل‌های اکسل نیتیو را مستقیماً و بدون نیاز به نصب بودن Microsoft Excel تولید می‌کند.

در MachineryManagerEnterprise، کتابخانه ClosedXML به‌عنوان فناوری اصلی خروجی اکسل ارزیابی می‌شود.
