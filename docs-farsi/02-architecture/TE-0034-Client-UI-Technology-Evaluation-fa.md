⚠ اطلاعیه جایگزینی (2026-08-02): توصیه این ارزیابی (Avalonia UI) مستقیماً با TE-0010 — ارزیابی چارچوب دسکتاپ-موبایل، که .NET MAUI را انتخاب کرده بود، در تضاد بود. بر اساس تصمیم بازبینی معماری، .NET MAUI چارچوب کلاینت استاندارد شده است. این سند فقط برای سابقه تاریخی نگهداری می‌شود. برای تصمیم فعلی و لازم‌الاجرا به TE-0010 و ADR-0013 مراجعه کنید.

## هدف

هدف، ایجاد یک انتخاب فناوری یکپارچه است که تمام الزامات کارکردی و معماری را برآورده کند و در عین حال اصول معماری تمیز (Clean Architecture) را حفظ نماید.
فناوری‌های انتخاب‌شده باید موارد زیر را فراهم کنند:

- رابط کاربری دسکتاپ مدرن
- قابلیت چندسکویی
- معماری MVVM
- قابلیت نگهداری سازمانی
- عملکرد بومی
- تجربه غنی دسکتاپ
- پشتیبانی بلندمدت
- بهره‌وری عالی توسعه‌دهنده

## ۸. ارزیابی Avalonia UI

### نمای کلی

Avalonia UI یک چارچوب رابط کاربری چندسکویی مدرن برای برنامه‌های .NET است.
این چارچوب توسعه برنامه‌های دسکتاپ بومی را با استفاده از موارد زیر امکان‌پذیر می‌سازد:

- XAML
- MVVM
- رندرینگ با شتاب سخت‌افزاری
- کنترل‌های دسکتاپ بومی

برخلاف فناوری‌های فقط ویندوزی مانند WPF یا WinUI، Avalonia به‌طور یکسان در ویندوز، لینوکس و مک‌اواس اجرا می‌شود.
در MachineryManagerEnterprise، Avalonia UI به‌عنوان چارچوب اصلی برنامه دسکتاپ ارزیابی می‌شود.

### نقش معماری

```
        لایه تجاری
              │
              ▼
        ViewModelها
              │
              ▼
          Avalonia UI
      ┌──────────────────────┐
      │ ویندوز               │
      │ لینوکس               │
      │ مک‌اواس              │
      └──────────────────────┘
```

Avalonia لایه نمایش را پیاده‌سازی می‌کند در حالی که از منطق تجاری مستقل باقی می‌ماند.

### نقاط قوت معماری

مزایا شامل موارد زیر است:

- چارچوب دسکتاپ چندسکویی
- پشتیبانی XAML
- یکپارچه‌سازی بومی .NET
- رندرینگ با شتاب سخت‌افزاری
- معماری سازگار با MVVM
- اکوسیستم متن‌باز فعال
- ابزارهای عالی
- نقشه راه بلندمدت

### قابلیت‌های کارکردی

Avalonia از موارد زیر پشتیبانی می‌کند:

- رابط کاربری XAML
- اتصال داده
- فرمان‌ها
- استایل‌ها
- پوسته‌ها
- کنترل‌های سفارشی
- مدیریت پنجره
- رندرینگ High-DPI

### پشتیبانی چندسکویی

| پلتفرم|پشتیبانی|
| ---|---|
| ویندوز|✅|
| لینوکس|✅|

باینری‌های یکسان برنامه می‌توانند تمام سیستم‌عامل‌های دسکتاپ پشتیبانی‌شده را هدف قرار دهند.

### سازگاری با MVVM

Avalonia بر اساس اصول MVVM طراحی شده است.
این چارچوب به‌طور طبیعی با موارد زیر یکپارچه می‌شود:

- CommunityToolkit.Mvvm
- تزریق وابستگی
- ICommand
- خاصیت‌های قابل‌مشاهده
- اعتبارسنجی داده

هیچ مصالحه معماری لازم نیست.

### عملکرد

Avalonia موارد زیر را فراهم می‌کند:

- رندرینگ با شتاب GPU
- موتور چیدمان کارآمد
- کنترل‌های مجازی‌سازی‌شده
- میزبانی بومی پنجره

عملکرد برای برنامه‌های دسکتاپ سازمانی **عالی** ارزیابی می‌شود.

### یکپارچه‌سازی با اکوسیستم مایکروسافت

این موضوع پیچیدگی یکپارچه‌سازی در سراسر راه‌حل را به حداقل می‌رساند.

### تجربه توسعه‌دهنده

مزایا شامل موارد زیر است:

- نحو آشنا XAML

- نرم‌افزار تجاری چندسکویی
- سیستم‌های قابل نگهداری بلندمدت
- معماری‌های دسکتاپ ماژولار

### ویژگی‌های عملیاتی

برنامه‌ها به‌صورت فایل‌های اجرایی بومی دسکتاپ توزیع می‌شوند.
هیچ وابستگی به سرور وب اجرایی یا مرورگر وجود ندارد.

## ۹. ارزیابی FluentAvalonia

### نمای کلی

FluentAvalonia یک کتابخانه مؤلفه رابط کاربری است که به‌طور خاص برای Avalonia UI ساخته شده است.
این کتابخانه سیستم طراحی Fluent مایکروسافت را پیاده‌سازی می‌کند و در عین حال کاملاً با موتور رندرینگ Avalonia سازگار است.
در MachineryManagerEnterprise، FluentAvalonia به‌عنوان کتابخانه اصلی مؤلفه‌های بصری مورد استفاده توسط کلاینت دسکتاپ ارزیابی می‌شود.
این کتابخانه جایگزینی برای Avalonia UI نیست؛ بلکه با ارائه کنترل‌های Fluent درجه سازمانی، Avalonia را گسترش می‌دهد.

### نقش معماری

```
      لایه تجاری
            │
            ▼
      ViewModelها
            │
            ▼
       Avalonia UI
            │
            ▼
  کنترل‌های FluentAvalonia
            │
            ▼
     برنامه دسکتاپ
```

FluentAvalonia مؤلفه‌های نمایش را فراهم می‌کند در حالی که Avalonia همچنان چارچوب رابط کاربری زیربنایی باقی می‌ماند.

### نقاط قوت معماری

مزایا شامل موارد زیر است:

- یکپارچه‌سازی بومی با Avalonia
- پیاده‌سازی طراحی Fluent مایکروسافت
- ظاهر دسکتاپ مدرن
- کنترل‌های سازمانی غنی
- زبان بصری یکپارچه
- جامعه فعال
- توسعه‌پذیری عالی
- سازگاری بلندمدت با Avalonia

### قابلیت‌های کارکردی

FluentAvalonia موارد زیر را فراهم می‌کند:

- NavigationView
- InfoBar
- ContentDialog
- CommandBar
- TeachingTip
- کنترل‌های تنظیمات
- آیکون‌های Fluent
- استایل‌دهی مدرن

### یکپارچه‌سازی با طراحی Fluent

این کتابخانه اصول طراحی Fluent مایکروسافت را پیاده‌سازی می‌کند، شامل:

- فاصله‌گذاری یکپارچه
- تایپوگرافی مدرن

FluentAvalonia به‌طور قابل‌توجهی موارد زیر را بهبود می‌بخشد:

- یکپارچگی بصری

رابط حاصل شباهت زیادی به برنامه‌های دسکتاپ مدرن مایکروسافت دارد.

### پشتیبانی از پوسته

### سازگاری با اکوسیستم مایکروسافت

FluentAvalonia از نظر بصری با موارد زیر همسو است:

- ویندوز ۱۱
- سیستم طراحی Fluent مایکروسافت
- برنامه‌های دسکتاپ مدرن مایکروسافت

این موضوع بدون ایجاد وابستگی‌های فقط ویندوزی، رابط آشنا در اختیار کاربران قرار می‌دهد.

### عملکرد

از آنجا که FluentAvalonia مستقیماً بر پایه کنترل‌های Avalonia ساخته شده است، عملکرد رندرینگ عالی باقی می‌ماند.

## ۱۰. ارزیابی CommunityToolkit.Mvvm

### نمای کلی

CommunityToolkit.Mvvm چارچوب رسمی MVVM مایکروسافت برای برنامه‌های مدرن .NET است.
این چارچوب زیرساخت سبک‌وزن MVVM را فراهم می‌کند و در عین حال کاملاً با اکوسیستم مایکروسافت .NET همسو است.
برخلاف چارچوب‌های MVVM بزرگتر، CommunityToolkit.Mvvm بر سادگی، تولید کد در زمان کامپایل و حداقل سربار زمان اجرا تمرکز دارد.
در MachineryManagerEnterprise، CommunityToolkit.Mvvm به‌عنوان چارچوب اصلی MVVM ارزیابی می‌شود.

### نقش معماری

```
لایه تجاری
      │
      ▼
 ViewModelها
      │
CommunityToolkit.Mvvm
      │
      ▼
 Avalonia UI
```

این چارچوب زیرساخت MVVM را پیاده‌سازی می‌کند و در عین حال ViewModelها را از فناوری‌های نمایش مستقل نگه می‌دارد.

### نقاط قوت معماری

مزایا شامل موارد زیر است:

- چارچوب رسمی MVVM مایکروسافت
- پیاده‌سازی مبتنی بر Source Generator
- حداقل سربار زمان اجرا
- یکپارچه‌سازی قوی با .NET
- قابلیت نگهداری عالی
- مستندسازی عالی
- پشتیبانی فعال مایکروسافت

## ۱۱. ارزیابی ReactiveUI

### نمای کلی

ReactiveUI یک چارچوب MVVM است که حول Reactive Extensions (Rx) و اصول برنامه‌نویسی واکنشی ساخته شده است.
این چارچوب قابلیت‌های پیشرفته‌ای برای برنامه‌هایی فراهم می‌کند که به موارد زیر نیاز دارند:

- انتشار واکنشی وضعیت؛
- گردش‌های کاری پیچیده ناهمگام؛
- جریان‌های داده قابل‌مشاهده؛
- برنامه‌نویسی واکنشی تابعی.

در MachineryManagerEnterprise، ReactiveUI به‌عنوان یک چارچوب MVVM جایگزین ارزیابی می‌شود.

### نقش معماری

```

      │

      │
ReactiveUI
      │
Reactive Extensions
      │
 Avalonia UI
```

ReactiveUI الگوی سنتی MVVM را با معرفی مفاهیم برنامه‌نویسی واکنشی در سراسر برنامه گسترش می‌دهد.

### نقاط قوت معماری

مزایا شامل موارد زیر است:

- پشتیبانی عالی از ناهمگام‌سازی

- جامعه قوی
- معماری انعطاف‌پذیر

### قابلیت‌های کارکردی
