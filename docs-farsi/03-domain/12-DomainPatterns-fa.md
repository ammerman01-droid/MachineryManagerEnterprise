# ۱. هدف

این سند الگوهای معماری تکرارشونده کسب‌وکار را که در کل دامنه MachineryManagerEnterprise استفاده می‌شوند، تعریف می‌کند.

برخلاف مشخصات کسب‌وکار (Business Specifications) که قابلیت‌های فردی را توصیف می‌کنند، الگوهای دامنه ساختارهای کسب‌وکاری قابل استفاده مجدد را تعریف می‌نمایند.

---

# ۲. الگوهای کلیدی

## DP-001 — الگوی عملیات کسب‌وکار (Business Operation Pattern)

اشیاء کسب‌وکار هرگز مستقیماً خود را ویرایش نمی‌کنند. هر تغییر از طریق یک عملیات کسب‌وکار انجام شده که رویدادهای تغییرناپذیر منتشر می‌کند و تاریخچه را شکل می‌دهد.

```text
عملیات کسب‌وکار (Business Operation)
          │
          ▼
رویداد کسب‌وکار (Business Event)
          │
          ▼
تاریخچه کسب‌وکار (Business History)
          │
          ▼
وضعیت فعلی (Current State Projection)
```

## DP-002 — الگوی پروجکشن / نمای اشتقاقی (Projection Pattern)

وضعیت فعلی یک سیستم منبع حقیقت نیست؛ بلکه یک نمای اشتقاقی (Projection) بر اساس سوابق تاریخی تغییرناپذیر است.

## DP-003 — الگوی چرخه حیات (Lifecycle Pattern)

مدلی یکپارچه برای مدیریت چرخه حیات اشیاء کسب‌وکار طولانی‌مدت از زمان خرید/ایجاد تا از رده خارج شدن.

## DP-004 — الگوی روابط (Relationship Pattern)

مدلی برای مدیریت روابط عملیاتی بین موجودیت‌های مستقل (مانند تراکتور + تریلر) بدون ادغام شناسه‌های آن‌ها.

## DP-005 — الگوی تفکیک برنامه‌ریزی از اجرا (Planning vs Execution Pattern)

پیش‌بینی و دستورکارها نشان‌دهنده نیت هستند؛ در حالی که عملیات اجراشده نشان‌دهنده واقعیت تاریخی است. این دو هرگز روی یکدیگر بازنویسی نمی‌شوند.

## DP-006 — الگوی داده‌های پایه (Master Data Pattern)

تعریف یک مرجع واحد و معتبر برای داده‌های پایه سازمانی (مانند کاتالوگ قطعات، سازندگان، کدهای خرابی) جهت استفاده توسط تمام ماژول‌ها.
