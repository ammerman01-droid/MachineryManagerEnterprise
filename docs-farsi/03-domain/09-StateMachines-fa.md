# ۱. هدف

این سند ماشین‌های حالت چرخه حیات موجودیت‌های اصلی کسب‌وکار را تعریف می‌کند.

هر انتقال حالت (Transition) باید قوانین کسب‌وکار تعریف‌شده در پروژه را برآورده سازد.

ماشین حالت موارد زیر را مشخص می‌سازد:
- حالت‌های معتبر (Valid States)
- انتقال‌های مجاز (Allowed Transitions)
- انتقال‌های غیرمجاز (Forbidden Transitions)
- رویدادهای تحریک‌کننده (Trigger Events)

---

# ۲. اصول ماشین‌های حالت

- حالت‌ها محدود و مشخص هستند.
- حالت‌ها مانعةالجمع هستند (در هر لحظه تنها یک حالت فعال وجود دارد).
- تاریخچه تمامی حالت‌های قبلی حفظ می‌شود.
- انتقال‌های غیرمجاز توسط لایه دامنه رد می‌شوند.
- انتقال‌های موفق باعث انتشار رویدادهای دامنه می‌گردند.

# ۳. چرخه حیات موجودیت‌های اصلی

## ۳.۱ چرخه حیات دارایی (Asset Lifecycle)

```text
پیش‌نویس (Draft)
   │
   ▼
ثبت‌شده (Registered)
   │
   ▼
راه‌اندازی‌شده (Commissioned)
   │
   ▼
عملیاتی (Operational) ◄──► غیرفعال (Inactive)
   │                           │
   └─────────────┬─────────────┘
                 ▼
          از رده خارج (Retired)
                 │
                 ▼
          اسقاط / فروخته‌شده (Disposed)
```

## ۳.۲ چرخه حیات موتور (Engine Lifecycle)

در انبار (Stored) ◄──► نصب‌شده (Installed) ──► جداشده (Removed) ──► زیر تعمیر (Under Repair) ──► بازسازی‌شده (Rebuilt) ──► در انبار (Stored)

حالت نهایی: از رده خارج (Retired) / اسقاط.

## ۳.۳ چرخه حیات نگهداری و تعمیرات (Maintenance Lifecycle)

برنامه‌ریزی‌شده (Planned) ──► زمان‌بندی‌شده (Scheduled) ──► در حال انجام (In Progress) ──► تکمیل‌شده (Completed)

حالت جایگزین: زمان‌بندی‌شده ──► لغو‌شده (Cancelled)
