# هدف

این سند تصمیم‌گیری معماری، ابزارها و فرآیندهای ساخت، بسته‌بندی و استقرار (CI/CD) پلتفرم MachineryManagerEnterprise را تعیین می‌کند.

---

# ۱. زمینه و مسئله (Context)

بر اساس ارزیابی فنی TE-0031، پلتفرم نیازمند یک پایپ‌لاین ساخت و استقرار یکپارچه، تکرارپذیر و سازگار با سیستم‌های مختلف (On-Premise، Cloud، Hybrid) است.

---

# ۲. تصمیم (Decision)

پلتفرم ابزارها و فناوری‌های زیر را برای ساخت و استقرار اتخاذ می‌کند:

| مسئولیت | فناوری تاییدشده |
|-----------------|------------------------|
| **پلتفرم ساخت** | **.NET 10 SDK** |
| **کانتینرسازی** | **Docker** |
| **ارکستراسیون محلی** | **.NET Aspire** |
| **یکپارچه‌سازی مداوم (CI)** | **GitHub Actions** |
| **جایگزین سازمانی (ALM)** | **Azure DevOps** (اختیاری) |

- **.NET 10 SDK**: ابزار اصلی و مرجع برای restore، build، test و publish است.
- **Docker**: استاندارد کانتینرسازی برای اطمینان از یکسانی استقرار در تمامی محیط‌ها.
- **.NET Aspire**: ابزار ارکستراسیون برنامه‌های توزیع‌شده محلی در زمان توسعه.
- **GitHub Actions**: پلتفرم اصلی CI/CD برای اتوماسیون تست‌ها و ساخت.
- **Azure DevOps**: جایگزین اختیاری برای سازمان‌هایی که از اکوسیستم مایکروسافت/آژور استفاده می‌کنند.

---

# ۳. پیامدها (Consequences)

پیامدهای مثبت:
- ساخت‌های تکرارپذیر و قطعی در تمامی محیط‌ها؛
- استقرار مبتنی بر کانتینر یکنواخت؛
- پشتیبانی کامل از استقرارهای On-Premise، Cloud و ترکیبی.
