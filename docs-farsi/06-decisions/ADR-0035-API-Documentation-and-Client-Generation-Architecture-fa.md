# زمینه و بستر (Context)

سند `TE-0021 — ارزیابی فناوری مستندسازی رابط برنامه‌نویسی و تولید کلاینت` تصویب شده بود اما هیچ سند ثبت تصمیم معماری (ADR) متناظری برای آن وجود نداشت. پلتفرم نیازمند یک رویکرد منسجم و مستقل از فروشنده برای توصیف رابط‌های برنامه‌نویسی (APIs) خود و تولید SDKهای کلاینت برای مصرف‌کنندگان داخلی و مصرف‌کنندگان آینده خارجی است.

---

# تصمیم (Decision)

سامانه MachineryManagerEnterprise معماری مستندسازی API و تولید کلاینت زیر را اتخاذ می‌نماید که رسمی‌سازی سند TE-0021 است:

| مسئولیت | فناوری انتخاب‌شده |
|----------------|----------------------|
| استاندارد قرارداد API | OpenAPI 3.x |
| مستندسازی تعاملی | Scalar |
| تولید SDK کلاینت اصلی | NSwag |
| تولید SDK چندزبانه | Kiota (اختیاری، آینده) |
| رابط کاربری قدیمی مستندسازی | Swagger UI (صرفاً برای سازگاری) |

سند استاندارد و رسمی OpenAPI باید به صورت بومی از ASP.NET Core تولید گردد. ابزار Scalar رابط کاربری اصلی مستندسازی تعاملی است؛ ابزار Swagger UI صرفاً برای حفظ سازگاری عقبروی نگهداری می‌شود.

---

# محرک‌های تصمیم‌گیری (Decision Drivers)

- بی‌طرفی نسبت به فروشنده (OpenAPI به عنوان استاندارد صنعت)
- همراستایی با .NET 10 و تجربه توسعه‌دهنده (Scalar)
- تولید کلاینت بالغ C# (NSwag)
- قابلیت نگهداری بلندمدت

---

# گزینه‌های بررسی‌شده (Alternatives Considered)

برای مقایسه کامل کاندیداها در میان رابط‌های کاربری مستندسازی و تولیدکنندگان کلاینت، به TE-0021 مراجعه نمایید.

---

# پیامدها (Consequences)

**مثبت (Positive)**

- یک قرارداد API واحد، استاندارد و قابل خواندن توسط ماشین (OpenAPI).
- تولید خودکار و منسجم SDKهای کلاینت.

**منفی / سبک‌سنگین‌ها (Negative / Trade-offs)**

- نگهداری دو رابط کاربری مستندسازی (Scalar + Swagger UI قدیمی) در طول دوره گذار.

---

# تاثیر معماری (Architecture Impact)

- صرفاً لایه Presentation (پروژه API). بدون هیچ اثری بر لایه‌های Domain یا Application.

---

# نکات پیاده‌سازی (Implementation Notes)

- فعال‌سازی تولید بومی OpenAPI در ASP.NET Core.
- پیکربندی Scalar به عنوان مسیر پیش‌فرض مستندسازی؛ حفظ Swagger UI صرفاً در جایی که ابزارهای موجود به آن وابسته‌اند.
- تولید SDKهای کلاینت از طریق NSwag به عنوان بخشی از خط لوله ساخت (Build Pipeline).
